# 営業日報メモ

**商談のあとに1分話すだけで、上司にそのまま送れる日報ができるアプリです。**

B2B営業の現場経験をもとに、「日報は大事だが、書く時間が取れない」という課題を解決するために作りました。

▶ **デモ動画（約90秒）：** https://youtube.com/shorts/CvW0hgxGIY4

▶ **ブラウザで試す（APIキー不要のサンプルつき）：** https://eigyo-nippo-8msrkvm5krthjpzykqlpbi.streamlit.app/

## 解決したい課題

- 外回りの営業は、帰社後や移動中にまとめて日報を書くため、**記憶が薄れて内容が粗くなる**
- 「次回アポ」や「宿題(ToDo)」が文章に埋もれ、**抜け漏れが起きる**
- 上司は、書き方がバラバラな日報から**状況を読み取るのに時間がかかる**

## このアプリでできること

| 手順 | 内容 |
|---|---|
| ① 話す | 商談直後にスマホやPCへ話しかける(キーボード入力も可) |
| ② AIが整理 | 訪問先・面談者・商談内容・次回アポ・ToDo の5項目に自動で整理 |
| ③ 項目ごとに直す | AIのまとめが違っていれば、項目単位で修正 |
| ④ 文章で仕上げて保存 | そのまま送れる文章に整形。テキスト／CSV(Excel対応)で保存 |

### 現場目線でこだわった点

- **「来週火曜」を具体的な日付に直す：** 訪問日を基準に、相対的な日付をカレンダーの日付へ変換します
- **書かれていないことは作らない：** メモにない情報は推測せず「未記載」「未定」と表示します
- **AI任せにしない：** 必ず人が確認・修正してから保存する流れにしています
- **ToDoに期限を付ける：** 「誰が見ても次に何をすればいいか分かる」形で抜き出します

## まず試す(APIキー不要)

```bash
cd eigyo-nippo
pip install -r requirements.txt
streamlit run app.py
```

画面の **「🧪 サンプルで試す」** を押すと、架空の商談メモと、AIが整理した結果の例が表示されます。APIを使わないので料金はかかりません。

## 自分の声で使う

録音の文字起こしとAIによる整理には、APIキーが必要です。

| もの | 用途 | 必須？ |
|---|---|---|
| OpenAI APIキー | 録音の文字起こし＋日報への整理 | これ1つで全部動きます |
| Anthropic APIキー | 日報への整理をClaudeで行う | 任意(入れるとClaudeを優先) |

`.streamlit/secrets.toml` を作って書きます(このファイルは `.gitignore` によりGitHubには上がりません)。

```toml
OPENAI_API_KEY = "sk-..."
# ANTHROPIC_API_KEY = "sk-ant-..."
```

画面左のサイドバーにキーを入力しても動きます。APIは従量課金のため、各管理画面で月の利用上限を設定しておくと安心です。

## 使っている技術

- Python / Streamlit(画面)
- OpenAI API(音声の文字起こし、日報への整理)
- Anthropic API(日報への整理・任意)
- 開発にはAIコーディング支援(Claude)を活用

## 今の制限(試作版)

- 「一覧」はページを閉じると消えます(CSVで保存してください)
- 商談内容は、文字起こしと整理のためにOpenAI(Claude利用時はAnthropic)のAPIへ送られます。実際の顧客情報を扱う場合は、所属先のAI利用ルールを確認してください
- スマホのブラウザで録音するには、HTTPSで公開された環境が必要です
